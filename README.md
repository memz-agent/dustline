# DUSTLINE — Kestrel Depot

An original round-based tactical FPS in the browser, built with three.js. You and two Warden bot teammates attack a freight-yard depot held by three Vulture bot defenders: plant the breach charge at site A or B (or eliminate the defenders), manage a round economy, and be first to 7 rounds.

- 3v3 rounds with bot teammates and enemies that buy, push, hold, plant and defuse
- Economy and buy menu: SMG, rifle, DMR, armor, grenade — four weapons with distinct damage, spread, recoil and falloff
- Accuracy-focused gunplay: movement/crouch bloom, tracers, hitmarkers, killfeed, damage-direction indicator
- Procedural WebAudio gunfire, footsteps, plant beeps and explosions — no audio files, no network requests

## Run it

```sh
node serve.ts   # then open the printed local URL
```

Or open `game/index.html` in any WebGL2-capable browser.
